Entrar al panel

Pegue aquí su llave de acceso de GitHub. Esta llave solo sirve para esta web y queda guardada únicamente en este equipo.

¿No tiene la llave? Cómo crearla (una sola vez)
  1. Inicie sesión en GitHub y abra esta página para crear la llave.
  2. En Token name escriba: Panel ricardolondono.com. En Expiration elija No expiration (o la fecha que prefiera).
  3. En Repository access elija Only select repositories y marque solo el repositorio ricardolondono-web.
  4. En Permissions → Repository permissions, busque Contents y cámbielo a Read and write. No active nada más.
  5. Pulse Generate token, copie la llave (empieza por github_pat_) y péguela arriba.

Guarde la llave en un lugar seguro. Si la pierde o cree que alguien la vio, bórrela en GitHub y cree otra igual.
